# Tailwind Project

A React and Tailwind CSS frontend project built with Vite.

## Technologies

* React
* Tailwind CSS
* JavaScript
* HTML
* CSS
* Vite

## Features

* Responsive navigation bar
* Home page
* About page
* Products section
* Reusable React components
* Responsive styling with Tailwind CSS

## Project Structure

```text
src/
├── Pages/
│   ├── Home.jsx
│   └── About.jsx
├── components/
│   ├── Navbar.jsx
│   ├── Footer.jsx
│   └── Products.jsx
├── assets/
├── App.jsx
├── main.jsx
└── index.css
```

## Getting Started

Install the project dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The project will then be available on the local development server.
